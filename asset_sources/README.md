# Phantom Ops character source assets

Source: Quaternius
License: CC0 1.0 Universal, as identified by the project maintainer.

These original FBX files are retained separately from the production
Godot project and are not directly included in the Android game export.

Models:
- Zombie
- ZombieSmooth
- BaseCharacter
- BlueSoldier_Female
- BlueSoldier_Male
- Soldier_Female

The isolated Godot 4.3 validation project imports these files and checks
their skeletons and expected animation clips.

Quaternius source: https://quaternius.com/
